# LLM2.0 项目架构与界面说明

## 一、项目架构图解

### 1. 整体架构

```
+------------------+     +------------------+     +------------------+
|                  |     |                  |     |                  |
|  用户界面层       |---->|  业务逻辑层      |---->|  API集成层       |
|  (React组件)     |<----|  (Hooks/Store)   |<----|  (Coze API)      |
|                  |     |                  |     |                  |
+------------------+     +------------------+     +------------------+
```

### 2. 数据流动示意图

```
+-------------+     +-------------+     +-------------+     +-------------+
|             |     |             |     |             |     |             |
| 用户输入     |---->| 状态更新    |---->| API请求     |---->| 响应处理    |
|             |     |             |     |             |     |             |
+-------------+     +-------------+     +-------------+     +-------------+
                                                              |
                    +-------------+                           |
                    |             |                           |
                    | UI更新      |<--------------------------+
                    |             |
                    +-------------+
```

### 3. 组件结构图

```
+------------------+
|                  |
|    App (根组件)   |
|                  |
+--------+---------+
         |
         v
+--------+---------+     +------------------+
|                  |     |                  |
|   ChatSidebar    |<--->|   ChatContent    |
|   (侧边栏组件)    |     |   (消息展示)     |
|                  |     |                  |
+------------------+     +--------+---------+
                                  |
                                  v
                         +--------+---------+
                         |                  |
                         |    ChatInput     |
                         |   (消息输入)     |
                         |                  |
                         +------------------+
```

## 二、核心组件交互

### 1. 消息发送流程

```
+-------------+     +-------------+     +-------------+
|             |     |             |     |             |
| ChatInput   |---->| Store更新   |---->| API请求     |
| (输入消息)   |     | (状态管理)  |     | (发送数据)  |
|             |     |             |     |             |
+-------------+     +-------------+     +------+------+
                                               |
+-------------+     +-------------+            |
|             |     |             |            |
| ChatContent |<----| Store更新   |<-----------+
| (显示消息)   |     | (接收响应)  |
|             |     |             |
+-------------+     +-------------+
```

### 2. 文件上传流程

```
+-------------+     +-------------+     +-------------+
|             |     |             |     |             |
| 文件选择     |---->| 上传请求    |---->| 获取文件ID  |
|             |     |             |     |             |
+-------------+     +-------------+     +------+------+
                                               |
                    +-------------+            |
                    |             |            |
                    | 关联消息    |<-----------+
                    |             |
                    +-------------+
```

## 五、状态管理详解

### 1. Zustand状态流转

```
+------------------+     +------------------+
|                  |     |                  |
|  组件状态更新     |---->|  全局状态更新    |
|  (本地State)     |     |  (Zustand Store) |
|                  |     |                  |
+------------------+     +--------+---------+
         ^                        |
         |                        v
         |                +-------+--------+
         |                |                |
         +----------------+  组件重渲染    |
                          |                |
                          +----------------+
```

### 2. 消息状态管理

```
+------------------+     +------------------+     +------------------+
|                  |     |                  |     |                  |
|  消息输入        |---->|  消息发送        |---->|  消息接收        |
|  (ChatInput)     |     |  (API请求)       |     |  (流式响应)      |
|                  |     |                  |     |                  |
+------------------+     +------------------+     +--------+---------+
                                                           |
         +--------------------------------------------------+
         |
         v
+--------+---------+     +------------------+
|                  |     |                  |
|  状态更新        |---->|  UI渲染          |
|  (Store)         |     |  (ChatContent)   |
|                  |     |                  |
+------------------+     +------------------+
```
